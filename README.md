# 🧩 My Object-Oriented Programming (OOP) Projects in Python 

Hi! I'm Imane 👋  
These are a few small projects I made while learning Object-Oriented Programming (OOP) in Python.  
Each project helped me understand how classes, objects, and methods work together in real examples.

---

## 🚀 Projects Overview

### 1️⃣ Message Project  
This project simulates sending a message between two people.  
It asks for the sender, receiver, and content, then shows the message with the current date and time.

*What I learned:*
- How to create a class with an __init__ method  
- How to use the datetime module  
- How to handle user input with validation  

---

### 2️⃣ Profile Project  
This project collects basic user information — name, email, and the language they want to learn — and displays it.  

*What I learned:*
- How to validate email input  
- How to store data inside an object  
- How to print user-friendly output  

---

### 3️⃣ Product Project  
This one shows information about different products (like a drone, iPhone, and laptop).  
Each product has attributes such as name, price, quality, and rating.

*What I learned:*
- How to create multiple objects from the same class  
- How to display data clearly using methods  

---

## 🧠 What I Learned Overall
Through these small projects, I started to really understand:
- The idea of *classes and objects*  
- The use of **self** and **__init__**  
- How to make code more organized and reusable  
- How to interact with users and handle input
